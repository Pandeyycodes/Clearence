# Screenshot capture guide

The README references eight images in this folder. Capture each one, save it
with the exact filename below (PNG), and the README gallery fills in.

Setup: backend and frontend running, and the bundled demo already loaded
(sign in as `recruiter@clearance.local` / `demo1234`). On Windows, use
`Win + Shift + S` to snip a region, then save it here with the right name.

| File | Page / URL | What to show |
|---|---|---|
| `01-login.png` | `/login` | The sign-in card with the demo credentials hint |
| `02-intake.png` | `/` | The dropzone and the job-description box (paste `demo_data/jd.txt`) |
| `03-case-card.png` | `/` after screening one resume | The case card: category, match stamp, matched/missing skills, top terms, redacted text with the black redaction bars |
| `04-batch-table.png` | `/batch/<id>` | The ranked batch in table view, with the Export CSV button visible |
| `05-batch-grid.png` | `/batch/<id>` | The same batch after toggling to grid view |
| `06-csv-export.png` | spreadsheet | The exported CSV opened in Excel or Google Sheets |
| `07-compare.png` | `/compare` | Two or three candidates side by side with the unique-skill diff |
| `08-history-bias.png` | `/history` and a batch view | Case history plus the permanent bias-audit disclosure panel |

Tip for a clean look: use a browser window around 1280 px wide, and capture
the content area rather than the whole desktop.
